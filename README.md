# Terra X Correr

Lector i editor de roadbooks per a moto (Android).

## Com usar-la

1. Obre aquest enllaç al mòbil amb **Chrome**:
   `https://EL-TEU-USUARI.github.io/terra-x-correr/`

2. A Chrome → menú (⋮) → **Afegeix a la pantalla d’inici** / **Instal·la l’aplicació**

3. Ja la tindràs amb el logo i el nom **Terra X Correr**.

## Funcions

- Lectura de roadbooks en PDF
- Odòmetre (total + parcial), velocitat i CAP
- Pestanya d’instruments
- Editor de notes
- Crear roadbook automàticament des d’un fitxer GPX

Tot es desa només al telèfon (no hi ha núvol).
