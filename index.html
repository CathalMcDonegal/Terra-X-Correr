Manual d’instruccions

Guia ràpida de Terra X Correr per llegir roadbooks a moto.

1. Carregar un roadbook

A la pestanya Roadbook, toca el botó PDF i tria el fitxer PDF del teu roadbook. Cal internet la primera vegada (per carregar la llibreria PDF). Després funciona offline.

2. Navegar el roadbook

▲ (taronja) = retrocedir / pujar
▼ (verd) = avançar / baixar
− / + = fer el roadbook més petit o més gran (zoom)
Pantalla = pantalla completa

3. Odòmetre

L’odòmetre suma quilòmetres amb el GPS.
− / −− / ++ / + = ajustar (−0,1 / −0,01 / +0,01 / +0,1)
Rp = reset del parcial
Rt = reset del total (i del parcial)

4. Velocitat i direcció

La velocitat surt del GPS (km/h).
La direcció mostra una fletxa, els punts cardinals (N, NE, E…) i els graus. Dona permís d’ubicació i, si cal, d’orientació del telèfon.

5. Pestanya Instruments

Pantalla neta només amb odòmetres, velocitat, direcció i hora. Útil quan no necessites veure el PDF.

6. Reset total de l’app

El botó Reset tot (a la barra inferior) esborra el PDF, posa els odòmetres a zero i deixa l’app com al principi.

Consells per a moto

· Munti el telèfon en un suport estable
· Activa la ubicació precisa
· Carrega el PDF abans de sortir (amb cobertura)
· Usa pantalla completa per veure millor el roadbook
